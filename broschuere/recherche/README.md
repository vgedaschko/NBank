# Recherche & Faktenbasis

Alle Aussagen der Broschüre stützen sich auf diese verifizierte Faktenbasis (Stand 21.10.2026).

- `factbase.md` – lesbare Fassung, gruppiert nach Themen; jede Aussage mit Quelle (Richtliniennummer oder URL)
- `factbase.json` – maschinenlesbar, inkl. wörtlicher Belegzitate, Prüfstatus und offener Punkte

**Entstehung:** 8 parallele Recherche-Agenten (5 Deep-Reads der RL Mietwohnraum 2026, 3 Web-Recherchen auf nbank.de,
niedersachsen.de, voris, LSN) → Konsolidierung → jede Aussage von zwei unabhängigen Prüfern gegengeprüft
(Wortlaut-Prüfung und Kontext-/Irreführungsprüfung) → Vollständigkeitskritik → Nachrecherche → erneute Prüfung.

**Status-Werte:** `confirmed` = von beiden Prüfern bestätigt · `corrected` = durch Prüfer präzisiert/ergänzt.

**Primärquelle:** Richtlinie über die Gewährung von Zuwendungen zur Förderung von Mietwohnraum (RL Mietwohnraum 2026),
RdErl. d. MW v. 25.06.2026, Nds. MBl. 2026 Nr. 319 vom 01.07.2026 –
[PDF auf nbank.de](https://www.nbank.de/medien/nb-media/Downloads/Rechtliche-Grundlagen/Richtlinien/Richtlinie-F%C3%B6rderung-von-Mietwohnraum-(RL-Mietwohnraum-2026).pdf)

Offene Punkte, die nur die NBank klären kann (z. B. fortgeschriebene Bemessungsgrenzen zum 01.10.2026, Tilgungsmodalitäten),
stehen am Ende von `factbase.md`.
